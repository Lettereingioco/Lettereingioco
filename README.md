# Lettere in gioco

Sito di giochi didattici per l'ora di Lettere, a cura di Giorgio Guerra. Pubblicato con GitHub Pages su lettereingioco.it.

## Come si aggiorna

1. Aggiungi o modifica un gioco in `_strumenti/giochi.json`.
2. Metti il file del gioco in `giochi/<slug>/gioco.html` e imposta `"stato": "pronto"`.
3. Lancia `python3 _strumenti/costruisci.py`: rigenera tutte le pagine.
